### 底图目标识别

- 功能说明

​	识别底图中的目标检测信息

- 接口路由

  POST结果

- 输入参数

  | 字段      | 类型   | 解释     | 备注                                                 |
  | --------- | ------ | -------- | ---------------------------------------------------- |
  | target    | String | 目标名称 | 可能有，也可能没有，比如飞机。传空的时候识别所有目标 |
  | tiff_path | String | 底图路径 | 服务器上底图的路径                                   |

- 返回示例

  ```
  {
      "code": 200,
      "msg": "",
      "data":	[
         	      {
                     targetName: // 目标名称
                     leftTopX: // 左上角x坐标百分比
                     leftTopY: // 左上角y坐标百分比
                     leftBotX: // 左下角x坐标百分比
                     leftBotY: // 左下角y坐标百分比
                     rightTopX: // 右上角x坐标百分比
                     rightTopY: // 右上角y坐标百分比
                     rightBotX: // 右下角x坐标百分比
                     rightBotY: // 右下角y坐标百分比
                     center_x:  // 中心点x坐标百分比
                     center_y:  // 中心点纵坐标百分比
                     leftTopLon: // 左上角经度
                     leftTopLat: // 左上角纬度
                     leftBotLon: // 左下角经度
                     leftBotLat: // 左下角纬度
                     rightTopLon: // 右上角经度
                     rightTopYLat: // 右上角纬度
                     rightBotXLon: // 右下角经度
                     rightBotYLat: // 右下角纬度
                     center_Lon:  // 中心点经度
                     center_Lat:  // 中心点纬度
                                  // 检测时间  
                     fusionSource:			  // 融合信源
             		   fusionBasis:			  // 融合依据
             		   fusionInfo:			  // 融合信息
             		   auxInterpretationInfo:  // 辅助判读信息 
                },
                {}
      ]
      
   }
  ```

  

### 切片目标识别

- 功能说明

​	输入切片，识别目标结果

- 接口路由

  POST结果

- 输入参数
 {
  	pointPath:	// 多张切片数组，切片路径
 }
  ```
  {
  	
    basePath:	// 底图路径
  	pointPath:	// 切片路径
  	lon:		// 切片中心点经度
  	lat:        // 切片中心点纬度
  	height:		// 切片图片高度
  	width:		// 切片图片宽度
  	
  }
  ```

当前传入切片的时候会传两张图

一张大图还有很多对应的切片图

大图你就进行base_map进行检测识别但是切片图就直接进行分类

传入切片路径的时候是否增加识别类型

是否规划 大图初筛 -> 裁剪切片 -> 细粒度识别 的二级流水线。

需要修改你的 Agent 调度逻辑（可能是 planning_agent.py 或 scheduler_center.py）
